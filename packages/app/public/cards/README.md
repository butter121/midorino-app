# カードの絵（ラスター画像）の置き場

ここに置いた画像は、ビルドするとそのまま `dist/cards/` に入り、画面が自動で使います。
画像が無いカードは今までどおり SVG の絵で表示されます（一覧に無い id は取りに行きません）。

## 置くもの

| ファイル | 中身 | 大きさの目安 |
| --- | --- | --- |
| `<id>.webp` | 大きい版（カードの「大」表示・詳しく見る画面） | 縦長 3:4、**480×640**（最低 384×512）、品質 80 前後、1 枚 60 KB 以下が目安 |
| `<id>-s.webp` | 小さい版（44〜76px のカード・リーダーの丸） | 縦長 3:4、**192×256**、品質 75 前後、1 枚 15 KB 以下が目安 |
| `index.json` | 置いた絵の一覧（**必須**。無いと絵は1枚も使われない） | `{"v": "2026-11-18", "ids": ["l_riku", "o_butcher", ...]}` |

- `<id>` はカードの id そのまま（例 `l_riku`, `o_butcher`, `w_trophy_axe`, `a_tower_shield`, `t_anvil`, `s_lure`, `g_spear`, 段階カードは `tavern` など、依頼 `q_kill4` / `sq_hunt`, 古代の品 `an_crown_1`）。全 346 枚の id は `node tools/kiridani2/cards-csv.mjs` の CSV の1列目。
- 1 つの id につき **2 枚とも** 置く（片方だけだとその大きさでは SVG の絵になる）。
- `index.json` の `ids` に入っている id だけ画像を使う。`v` は絵を差し替えたら変える文字列（画像の URL に `?v=` として付き、ブラウザとサービスワーカーの手元の古い絵が取り直される）。
- 元絵は縦長 3:4（例 768×1024）で作り、そのまま縮小する。画面では **正方形に切り抜いて** 表示する：
  - 人物（リーダー・職能）：上から 6%〜81% の範囲（顔を上寄りに）
  - それ以外：上下 12.5% ずつ切った真ん中
  → 大事なもの（顔・品物）は中央の正方形に収める。文字・枠は描かない（枠は画面が重ねる）。リーダーは背景色なしで描く（古い金の縁取りが目印になる）。
- 画面が重ねるもの：左上の三角（種類の色と印）と縁（リーダーは四隅に飾り）。四隅には大事なものを置かない。強い動き（engine タグ）は画面に出さない（プレイヤーが見つけるもの）。

## 置いたあと

`packages/app` で `npm run build`。`base: './'` なので GitHub Pages のサブフォルダでもそのまま動く（画像は `cards/<id>.webp` の相対パスで読む）。
