# 霧谷の冒険者団 v2 — 実装仕様（エンジン・カードデータ共通）

元の計画：「ルール一新の計画（最終版）」 https://claude.ai/artifact/3CK1sjpau4sjuVGgXVcPxA
K さんの決定はすべてこの仕様に反映済み。迷ったら計画を優先し、ここに追記する。

v2 は **TypeScript で直接書く**（v1 の Python → TS 移植はしない）。シミュレーションも Node で回す。
置き場所：`packages/engine/src/kiridani2/`。v1（`kiridani/`）は触らない（アプリは移行完了まで v1 のまま）。

> **2026-11 の作り直し**（次の次の更新）：弱点・後衛・種族への特攻を取り除き、カードを全部作り直した。§1〜§9 と食い違うところは **§12 が優先**。

## 0. 方針
- **大型アップデートとして出す**（K さん決定）。今の UI と機能はすべて残す：盤面、トレイ、タップで詳細表示、アニメ、横画面、オンライン対戦、チャット、退室中の AI 代行と復帰、ひとりプレイ、PWA。v2 用には session と審判（net.ts 相当）を v1 と同じ形で用意し、既存の画面にはつなぎ替えるだけで済むようにする。
- 乱数は `rng.ts` の mulberry32（v1 と同じ）。正規分布は Box–Muller、±2.5σ を超えたら引き直し。
- エンジンはジェネレーター（v1 と同じ「選択は yield で外に出す」形）。人間・AI・オンライン審判が同じ入口を使う。
- カード・リーダー・行動マス・共通の装備・魔物の型・依頼はすべて **データ（JSON/TS の定数）**。効果は §8 の効果 DSL で書く。カード固有の if 文をエンジンに書かない。
- 出来事（GameEvent）を出す。画面とアニメはそれを見る（v1 の types.ts を参考に新しく定義）。

## 1. 試合の長さ
- 年数 Y ∈ {5, 10, 15}、ラウンド R = 4Y。季節は 春夏秋冬の順。冬（R%4==0）に維持費と襲撃。
- 進み具合 t = (r-1)/(R-1)（0〜1）。
- 主：4体＋古竜。5年＝1〜4年目の冬、10年＝2・4・6・8年目、15年＝3・6・9・12年目。古竜は最後の冬。
- 補充の準備：10年＝4年目・7年目の春、15年＝4・7・10・13年目の春。職能1枚（5見て1）＋品物2枚（種類は自由に選び、各5見て1）。
- 分野表のしきい値：5年を基準に 10年 ×1.6、15年 ×2.0（切り上げ）。定数で持つ。

## 2. 準備段階
0. 始めの先手：くじ（`startSeat(seed, n)`。本体の乱数とは別の流れなので、ほかのくじは変わらない。`GameOptions.first` で固定できる＝試しだけ）。出来事 `first_player`。準備の各段階・補充・手番はこの先手から時計回り。
1. リーダー：最後の手番の人（先手の1つ前の席）から順に、残りの山から5人見て1人。残り4人は山へ戻す。
2. 職能×3：各回、職能の山から5枚見て1枚。残りは山へ戻して混ぜる。全員同時（エンジンでは席順に聞いてよいが、互いに影響しない）。
3. 割合：武具・道具・秘術の合計5（各0〜5）。
4. 品物×5：選んだ種類の山から5枚見て1枚。種類の順番は自分で選ぶ（1枚ずつ「次はどの種類」を聞く）。
5. 始めの2枚：手にした職能から1枚、品物から1枚を費用なしで出す。残りは手札。
6. 秘密依頼：2枚見て1枚（自分だけ見える）。
- 始めの持ち物：仲間2人（リーダー＋1人）、寝床3、食料3（＋手番の順の追加 v1 と同じ SEAT_FOOD。番手はくじの先手から数える）、金貨2、木材1、鉄1。

## 3. ラウンドの流れ
1. ラウンドの始め：段階カードを1枚めくる（§4）。たまるマスに資源を足す。蓄積効果（future）を受け取る。装備の持ち替え（AI の席だけ自動・無料）。魔物の出現（予告されていたものが巣に入る）と、次のラウンドの予告のくじ。
2. 手番：先手から順に、仲間1人を1つのマスに置く。全員置ききるまで。置く仲間は自分で選べる（Option.who。マスは空いている仲間1人、巣・主の巣は送る k 人。省略すればマスは空いている最初の仲間、戦闘は戦力の高い順）。
3. 戦闘の解決（巣・主の巣。待ち伏せは v1 と同じくラウンドの終わり）。
4. ラウンドの終わり：仲間が戻る。負傷の回復判定。冬なら維持費（仲間1人食料2、払えなければ不満1枚＝−3）と襲撃。
5. 先手：集会所に置いた人。いなければそのまま。

## 4. 行動マス
- 始めから：古の森（木材+3たまる）、鉄の坑道（鉄+3たまる）、薬草の野（薬草+3たまる）、魔石の泉（魔石+1たまる、取ると素材1も）、狩場（食料+3たまる）、依頼板（金貨2）、ギルド（職能を出す：食料1、2枚目以降は食料2）、鍛冶場（武具カードか共通の武器を1つ作る）、工房（道具カードか施設・寝床・防壁を1つ建てる）、交換所（§7）、広場（食料1か素材1。定員なし）、集会所（先手＋食料1。定員1）、巣（人数で 3〜4 個、v1 の NESTS）。
- 人数で増えるマス：v1 の min_p と同じ（雑木林・露店→「小さな交換所」・深い坑道・行商・霧の沢・見張り小屋）。
- 段階カード（各段階の候補から決まった枚数をくじで選び、順番もくじ）：
  - 段階1（必ず最初の年 R2〜R4、3枚全部）：酒場で募集、訓練場、遺跡の探索
  - 段階2（4枚、候補6）：城壁の普請、神殿への寄進、大市、対家の家族、行商隊、狩人の小屋
  - 段階3（4枚、候補6）：討伐隊、施設の強化、魔導書庫、若手の訓練、交易所の拡張、獣舎の開放
  - 段階4（4枚、候補6）：英雄の招聘、大鍛冶場、近辺の探索、ギルドの推薦、古代の祭壇、巡礼路
  - 段階5（4枚、候補6）：決戦の準備、凱旋、救護所、土地の開拓、王都の使者、宝物庫
  - 段階2〜5は残りのラウンドを4等分し、その中で均等にめくる（5年なら1ラウンド1枚）。
  - 各段階カードの効果は `data/stages.ts` に DSL で書く（§8 の do をそのまま使う）。
- たまるマスは取られないと毎ラウンド増える（アグリコラと同じ）。

## 5. 仲間・装備・守り
- 仲間の上限 6。寝床1つに1人（v1 と同じ）。
- 仲間ごとに：攻めの熟練（0〜3）、守りの熟練（0〜2）、武器1枠、防具1枠。リーダーも仲間の1人（リーダー専用の装備はリーダーだけ）。
- 戦力＝送った仲間ごとに（2＋攻めの熟練＋武器の戦力）＋ その他の効果。
- 守り＝送った仲間ごとに（1＋守りの熟練＋防具の守り）＋ 拠点の守り（防壁2つごとに+1）＋ その他。
- 反撃 − 守り を超えた分だけ、送った仲間が負傷（負傷した仲間は次のラウンド休む。薬草2で即回復。v1 の仕組みを簡単にしたもの）。後衛（長弓など）の仲間は反撃の対象にならない（全員後衛なら反撃0）。
- 戦闘の選び方：通常／確実に（v1 safe）／賭ける（gamble）／削るだけ（chip）／待ち伏せ（wait）／**守って戦う**（戦力−2、反撃−2）。
- 運命カード：v1 と同じ [-1,0,0,1,1,2]、個人の山。めくった値は公開なので残りも公開（合わせ `sync.fate` に小さい順で載せる。並びは伏せる）。冬の食料の見込み（`Game.upkeepNeed`）も `sync.upkeep` で全員に。
- 装備の持ち替え：人の席は自分で持たせる。装備を手に入れたとき（作った・始めの持ち物）に誰に持たせるか聞き（倉庫に置いてもよい）、自分の手番には無料で持たせる・はずす・ほかの仲間から持ち替えられる（Action `equip`。両手武器を持つ仲間は防具を持てず、持たせると防具は倉庫へ。リーダー専用はリーダーだけ）。AI の席はこれまでどおり自動（作った・雇った・鍛えた・ラウンドの始め）。余りは倉庫。交換所で売れる（共通の装備は作った費用の半分を金貨で、カードは定めた値）。
- 共通の装備（数に限り、4人基準。3人は−1、5〜6人は+1）：
  | id | 名前 | 場所 | 費用 | 効果 | 数 |
  |---|---|---|---|---|---|
  | g_spear | 木の槍 | 鍛冶場 | 木2 | 戦力+1、2人以上で挑むと+2 | 3 |
  | g_sword | 鉄の剣 | 鍛冶場 | 鉄2 | 戦力+2 | 3 |
  | g_bow | 長弓 | 鍛冶場 | 木2・素材1 | 戦力+2、後衛 | 2 |
  | g_staff | 魔石の杖 | 鍛冶場 | 魔石2 | 属性を選べる、弱点を突くと+2 | 2 |
  | g_wshield | 木の盾 | 訓練場 | 木2 | 守り+1 | 3 |
  | g_leather | 革鎧 | 訓練場 | 素材2 | 守り+1、回復が薬草1安い | 3 |
  | g_ishield | 鉄の盾 | 訓練場 | 鉄2 | 守り+2 | 2 |
  | g_mail | 鎖帷子 | 訓練場 | 鉄3・素材1 | 守り+2、戦闘1回につき負傷1人を防ぐ | 2 |
- 訓練場：選んだ仲間1人に攻めか守りの熟練+1（食料1）、または防具を1つ作る。熟練を上げる仲間は本人が選ぶ（AI・お任せは熟練の低い仲間）。
- 若手の訓練：まだその熟練がない仲間だけ、1段階目（0→1）だけ上げる（op の `fresh`）。
- 遺跡の探索：武具・道具・秘術の山を1つ選んで3枚見て1枚、または古代の品。
- 共通の依頼：同じときに条件を満たした人（共闘・同じ冬など）は同着で、全員がその順位の名声を得る。次の人は同着の人数ぶん後の順位。

## 6. 魔物
- 型：v1 の 30 種（名前・種族・弱点・戦利品の種類）＋格（−1/0/+1）。1つの山。主の型は v1 の 4 種＋追加 2 種から4体をくじ（格+3）。
- 強さ＝round(5 + 8t + 格 + N(0,1.2²))、|N|≤2.5。（調整後の式は実装メモ「魔物の強さの底上げ」）
- 反撃＝round(強さ/3)、戦利品の個数＝round(強さ/2 + n(0,0.5²))（|n|≤1、型の資源の種類に配る）、証＝round(強さ/2.5 + n)、冬の襲撃＝round(強さ/4)。
- 予告：次のラウンドに出る魔物（くじの結果まで）が全員に見える。
- 古竜：強さ20固定、反撃4、最後の冬に全員で挑める（v1 と同じ）。（調整で主と同じ式に。実装メモ「魔物の強さの底上げ」）
- 冬の襲撃：その年に出て倒されていない魔物の襲撃の合計 − 拠点の守り を各自が受ける（1点＝名声−1、防壁で減る）。
- **主・古竜に参加しなかった罰**（K さん決定）：主（その年の冬）・古竜の戦いのとき、主の巣に仲間を送らなかった人は名声 −5（`BOSS_ABSENT`。勝ち負けによらない。誰も挑まなければ全員）。主に負けたときの襲撃+2・古竜に負けたときの全員 −3 はそのまま。
- 主・古竜の強さは見えている数字のまま（荒ぶりは削除。K さん決定）。
- 「回しきれたラウンド」の目標 7 割は、資源の量・費用・定員で合わせる（§11）。

## 7. 交換所・取引・寄進
- 交換所（相場なし）：1手番で「売る」か「買う」のどちらか、1種類を最大3個（カードで増やせる。「行商人」は売りと買いを同じ手番に）。
  - 買値：木1・鉄2・薬草1・食料1・魔石3・素材2（金貨）。売値：買値−1（最低1）。装備も売れる。
- 取引：v1 の人どうし・AI との取引をそのまま使う（各ラウンド1回、カードで増える）。
- 神殿への寄進（段階2）：金貨5→名声2、素材3→名声1（ラウンド1回）。
- 遺跡の探索：品物の山（武具・道具・秘術を混ぜた山）から3枚見て1枚、または「古代の品」の山から1枚。古代の品は 4 種×各3枚、同じ種類2つ＝名声2・3つ＝名声5、4種そろい＝名声6（重複不可、計画の「古代の品の組」）。

## 8. 効果 DSL（カード・リーダー・段階カード共通）
カード JSON：
```json
{
  "id": "o_lumberjack", "kind": "occ|weapon|armor|tool|spell|leader",
  "name": "木こり", "engine": ["gather"], "mech": "boost",
  "cost": {"food": 1}, "prereq": {"occs": 2}, "fame": 0,
  "slot": "weapon|armor|null", "two_hand": false, "rear": false, "leader_only": false,
  "power": 0, "guard": 0, "el": null, "vs_race": null,
  "effects": [ { "when": "...", "if": {...}, "do": [ ... ], "limit": "round|year|game|null" } ],
  "text": "（機械的な説明。仮。ローカルLLMで清書）"
}
```
- `engine`（強い動き）：hunt, gather, trade, fort, smith, family, arcane, beast, quest, ally, ruins, boss, bridge（橋渡し）。
- `mech`（効果の型）：boost, instead, combat, accrue, convert, social, endfame, action。
- `when`：
  - `use:<space>` そのマスを使ったあと（space は行動マスの id、`nest`＝どの巣でも、`any_accum`＝たまるマスのどれか）
  - `instead:<space>` そのマスに置いたとき、通常の効果の代わりにこれを選べる（選択肢として legal に出る）
  - `fight`（戦闘の計算中、送った仲間のうちこの装備の持ち手がいる／職能・道具は常に）、`win`、`lose`、`win_race:<race>`
  - `round_start`、`round_end`、`winter`、`game_end`
  - `build`（施設・寝床・防壁を建てた）、`hire`（仲間が増えた）、`craft`（装備を作った）、`sell`、`buy`、`trade`（取引が成立）、`donate`（寄進した）、`spell`（秘術を使った）、`tame`
  - `other:<space>` 他の人がそのマスを使ったとき（対人）
  - `play`（秘術：自分の手番に手札から使う。マスに置く代わりではなく、手番の前に1枚。使い切り）
  - `passive`（常に効く修正。下の mod）
- `if`：`{"season":"winter"}`、`{"min":{"comps":4}}`、`{"race":"beast"}`、`{"coop":true}`、`{"k_min":2}`、`{"has":"o_xxx"}`、`{"res_min":{"iron":1}}` など。必要になったら足す（足したらこの節に書く）。
- `do`（配列、順に実行）：
  - `{"gain":{"wood":1}}`、`{"pay":{"food":1}}`（払えなければその効果は使えない）
  - `{"convert":{"from":{"mat":2},"to":{"food":3}}}`（選択肢として出す）
  - `{"fame":2}`
  - `{"power":2}`、`{"guard":1}`、`{"counter":-1}`、`{"loot":1}`、`{"trophy":1}`、`{"str":-2}`（戦闘中だけ）
  - `{"extra_worker":1}`（このラウンドもう1人置ける）、`{"place_again":true}`（使ったマスにもう一度）、`{"ignore_full":true}`（埋まったマスに置ける）
  - `{"future":{"rounds":[1,2,3],"gain":{"food":1}}}`（次のラウンドから順に届く）
  - `{"draw":{"from":"occ|item|weapon|tool|spell|ancient","look":3,"take":1}}`
  - `{"hire":1}`（寝床が要る）、`{"hire_free":1}`（寝床不要）
  - `{"tame":true}`（戦わずに使い魔に。獣のみ）
  - `{"train":"atk|def"}`、`{"build":"wall|bed|facility","discount":{"wood":1}}`
  - `{"heal":1}`、`{"no_injury":1}`
  - `{"steal_gain":{"gold":1}}`（対人：他の人が使ったとき自分が得る。相手は失わない）
- `passive` の mod（`do` の代わりに `mod`）：`{"market_qty":2}`、`{"market_both":true}`、`{"trade_count":1}`、`{"accum_bonus":{"forest":1}}`、`{"cost_discount":{"kind":"weapon","res":{"iron":1}}}`、`{"upkeep":-1}`、`{"donate_rate":{"gold":4}}`、`{"base_guard":1}`、`{"pet_power":1}`、`{"hand_limit":1}` など。
- 上限 `limit`：`round`（ラウンド1回）、`year`、`game`。省略は無制限（`use:` の効果はマスを使うたびに1回）。
- エンジンが知らない op が来たら **例外**（テストで全カードを読み込んで確かめる）。

## 9. 名声
- 試合中：証、依頼（共通3枚：先着 4・3・2、秘密依頼1枚：達成で 4〜6）、寄進、古代の品の組、カードの fame。
- 終わりの分野表（0は−1）：倒した魔物の数（1〜3/4〜6/7〜9/10+）、倒した種族の種類（1〜2/3/4/5）、施設（1/2/3/4+）、防壁（同）、持たせた装備（1〜2/3〜4/5〜6/7+）、出した職能（1/2/3/4+）、使い魔（1/2/3/4+）→ 1〜4点。年数でしきい値を伸ばす（§1）。
- 仲間1人3点、金貨4枚で1点、不満1枚−3、襲撃1点−1。英雄ボーナスはなし。
- 主・古竜に参加しなかった：1回 −5（内訳 `absent`「主・古竜に不参加」）。

## 10. AI
- v1 の考え方（評価関数＋1手先読みの貪欲、novice/mid/expert のノイズ）を引き継ぐ。
- 準備段階で「目指す強い動き」を1〜2個決め（リーダーと見えたカードの engine タグの重なりで）、カード選び・マス選びでその動きの部品に重みを足す。
- 戦闘の見込み（v1 の safe/gamble/chip/wait の期待値）に「守って戦う」と装備・守りを入れる。

## 11. 測定（`tools/kiridani2/measure.ts`、Node で）
- 運の割合（v1 と同じ定義：同じ腕前の卓の分散 ÷ 腕前がばらばらの卓の分散）：目標 0.40 前後。
- 回しきれたラウンドの割合：プレイヤーが目指す強い動きの「一周」（カードの engine ごとに定義する手順の組：例 hunt＝巣で勝つ＋交換所で売る＋買う/作る）を、そのラウンドに全部できた割合。中盤以降（その動きの部品が2枚以上出たあと）で数える。目標 **7割程度**。
- 前のラウンドと同じ手順の繰り返し：3割以下。
- 強い動きごとの平均名声の差：±3 以内。戦わない動き（gather/trade/ruins）も含む。
- 名声の内訳：どの入り口も勝者の名声の 4 割以下。
- 5/10/15 年で上の値が大きく変わらない。

## 実装メモ（エンジン：仕様があいまいだったところの決め方）

- **選ぶ op**（craft/occ/build/exchange/train）：手順の最初の1つは「置く場所の選択肢」に広げる（x）。2つ目からは実行のときに `pick` で聞く（大鍛冶場・ギルドの推薦・若手の訓練）。
- **pay / convert を含む効果、選ぶ op を含む効果**は使うかどうか聞く（`effect`）。それ以外は自動。払えなければ使えない。
- **play の秘術の戦闘 op**（power・str・counter など）はそのラウンドの自分の戦闘すべてに効く。`place_again` をマスの外で使ったら、そのラウンドに最後に使ったマスの同じ手順をもう一度（たまるマスなら基本の量）。`tame` を巣の外で使ったら、獣のいる巣から選ぶ。
- **extra_worker**：休んでいない仲間がもう一度出る（巣にも出せる）。`ignore_full` は1回使うと消える（定員の埋まったマス・巣に1回置ける）。
- **装備**：持ち替えはラウンドの始めと装備が増えたときに自動（武器は戦力の高い順に攻めの熟練の高い仲間へ、防具は守りの高い順。両手武器の持ち手は防具なし、leader_only はリーダーだけ）。人が並べ替える操作はまだない。
- **戦闘**：巣は1ラウンドに2組まで（v1 NEST_CAP）。1回に送れるのは3人まで。弱点を突くと戦力+1（WEAK_BONUS、仕様にないので小さく）。使い魔は1体につき戦力 1＋pet_power。後押しは士気（食料1で+1、送った人数まで）・ポーション（薬草2で+1）・払う fight 効果・手札の fight 秘術。通常＝後押しなし、確実に＝最悪の運命でも勝てるまで、賭ける＝運命+1で勝てるまで（届かなければ使わない）、削るだけ＝後押しなし・負けたら傷+1、守って戦う＝戦力−2・反撃−2、待ち伏せ＝来なければラウンドの終わりに単独（賭ける）。運命は巣では置いた人（共闘は待っていた人）が1枚、主の巣は全員1枚ずつ。
- **負けたときの傷**：max(1, 合計戦力÷3) ＋ 削るだけなら+1（強さ−1 まで）。
- **反撃**：勝っても負けても受ける。守り＝送った仲間（1＋守りの熟練＋防具の守り）＋防壁2つごとに+1＋base_guard＋効果。超えた1点ごとに前衛1人が負傷（no_injury で減る）。全員後衛なら0。負傷の回復判定はラウンドの終わり（薬草2、革鎧などで安く）。払わなければ次のラウンド休み。
- **共闘の分け方**：戦利品は戦力の割合（端数は後から来た人）、証は round(証 × max(割合, 0.5))。主の巣も同じ（勝てば全員が「主を倒した」）。主に負ける／誰も挑まない → その冬の襲撃に主の襲撃値を足す。古竜に負けると全員 −3（v1 と同じ）。古竜に勝つと証10を割合で分け、参加者に+2。主・古竜の巣に仲間を送らなかった人は勝ち負けによらず名声 −5（`resolveLair` の `absentPenalty`。`fame` の出来事、reason は「主に参加しなかった」／「古竜に参加しなかった」、内訳は `Player.fame.absent`）。
- **冬の襲撃の拠点の守り**＝防壁1つにつき1＋base_guard（戦闘の守りの「防壁2つで+1」とは別。仕様の「防壁で減る」を素直に読んだ）。
- **不満**：足りない食料2ごとに1枚（端数切り上げ）。
- **2人**：巣は2つ、席順の追加食料は [0,1]。共通の装備の数は 2〜3人で −1（最低1）。
- **補充の準備**：品物2枚は1枚ずつ種類を選ぶ（割合の縛りなし）。
- **秘密依頼**は終わりにだけ数える（途中では見せない）。
- **手札の上限**：基本の上限はない（hand_limit は読み込むだけ）。
- **AI**：腕前 novice/normal/strong（v1 の novice/mid/expert）。ノイズ 2.0/0.8/0.12 に加え、novice は 25%、normal は 8% の手番で先読みせずに選ぶ（腕前の差をはっきりさせるため）。仲間を増やす価値は「最近の最善手の伸び」の移動平均から決める。

### 魔物の強さの底上げ（オーナーの指摘「簡単に倒せすぎる。終盤・主・古竜は少し苦戦したい」）
- **数値（data.ts の `MON_ROLL`・`DRAGON`）**：

- **結果（SIM_N=200、4人、strong、5/10/15年。勝率は挑んだ戦闘のうち）**：巣 序盤 90/91/91%・中盤 84/83/83%・終盤 71/70/76%（前は 92〜99%）。主 82/73/80%、挑まなかった 21/31/20%（前は 100%、戦力が強さを 13〜64 上回っていた）、送った仲間 9 人前後・後押し 2〜5 個。古竜 49/42/53%、挑まなかった 42/17/4%（前は 100%、+33〜69）。運の割合 0.58/0.36/0.41、回しきれたラウンド 63.6/73.1/76.8%、繰り返し 6〜9%、4割超の勝者 24/39/46%。強い動きの差（5年換算）boss −4.8/−8.8/−4.8（前と同じくらい）、family +9.1/+9.6/+9.8・hunt −4.6/−3.5/−6.7・beast（15年）+6.9・arcane（15年）+5.3 が外れ値。
- **主・古竜の参加の罰（K さん決定、バランスの測定はしていない）**：参加しないと −5 になったので、上の「挑まなかった割合」の数字は古い。
- **残りの課題**：主は「挑めば 7〜8 割」で、挑まない（割に合わないと見て見送る）が 2〜3 割。もっと強くすると AI は負けるより見送るほうを選ぶ（per 0.92/1.05 で勝率 61/65/69% だが見送り 48/39/29%）。family（仲間が多いほど 3 人組を何度も出せる）が強くなった。5 年の運の割合が上がった。

## 12. 作り直し（2026-11、次の次の更新）
§1〜§9 と食い違うところはこちらが優先。数値は `data.ts`、カードは `cards/*.ts`（効果は DSL、文は `cards/text.ts` が DSL から作る）。

### 取り除いたもの
- 弱点（属性・弱点を突く）と種族への特攻（`win_race`・種族の条件）。種族は残す（分野表の「倒した種族」、遺物の欠片）。主・古竜への特攻は残す。
- 後衛。反撃は送った仲間全員が受ける（守りが意味を持つように）。
- 職能の回数・ターンの制限。職能はすべて出したらずっと効く。

### 4種の品物とカードの枚数
- リーダー 50・職能 80・武器 80・防具 80・道具 80・秘術 80（使い切り 50＋何度でも使える秘術書 30）・使い魔 48・遺物 20（5種×4）。
- **装備**＝武器と防具（カードの無い共通の装備も含む）。共通の装備はすべて鍛冶場で作る（木の槍2・鉄の剣3・長弓2＋戦利品・魔石の杖1＋そのラウンドに秘術を唱えていれば+2、防具は従来どおり）。
- 準備の割合は武器・防具・道具・秘術の4種で合計 `ITEM_COUNT`=6。
- 武器は戦力を効率よく上げる。防具は守りのほか、攻撃の上乗せや「反撃を受けたとき」（when `hit`）の効果。道具はほぼずっと効き、武器・防具・秘術と組む。
- 重い品物は素材を多めに、または戦利品の出る数を減らした（`lootDiv` 3.5）。
- どの種類にも「欠点つき・見返り大」のカード（weight `curse`）が2枚以上。マイナスを組む例：反撃で受けた傷の数だけ名声（茨の騎士・茨の魔女アイビー）＋守りを下げる武器・防具・秘術。
- 使い切りの秘術・壊れた道具は山に戻して混ぜる（`recycle`）。

### 秘術
- 1手番に何回でも唱えられる。唱える費用は魔石1〜3、強さは費用に合わせる。
- 秘術書（何度でも）：手札から `learn` を払って身につけ、そのあとは唱える費用だけで1手番に1〜3回まで（カードごと）。使い切りより費用が重い。
- `spell_return`：使い切りを唱えたあと魔石1で手札に戻せる。

### 使い魔（獣使い）
- どの魔物でも捕まえられる。捕まえる＝勝つのに要る戦力が 強さ − 傷 ＋ 捕まえにくさ（格 −1/0/+1 → 1/2/4）。食料 強さ÷4（切り上げ）を払う。
- 使い魔の戦力＝強さ÷4（切り上げ、最大5）。型ごとに固有の効果（`cards/pets.ts`）。持てるのは3体（`pet_cap` で増える）、1回の戦闘に1体連れて行ける。

### 金貨の使い道
- 足りない資源を金貨で払える（作る・建てる・職能、1回に2個まで、買値+1）。冬の食料の代わり（金貨2で食料1）。傭兵（金貨2で戦力+1、送った人数まで）。魔石の代わり（カードの `gold_mana`）。
- 終わりの名声は金貨4で1（上限 4×年数倍率。カードで上限・レートが変わる）。

### 職能の手に入れ方・カードの手に入れ方
- 段階2に「弟子入り」（職能の山から見て1枚）。主・古竜に勝つと好きな品物の山から2枚見て1枚、主なら遺物も1枚。共通の依頼を達成すると職能か品物の山から2枚見て1枚。遺跡の探索は4種の山のどれかから、または欠片2。
- ギルドの食料：1枚目1、以降 2・2・3・3・4（`OCC_FOOD`）。

### 強い動き：商い・遺物集め
- 商い：素材を集めて売り、金貨を名声に（帳場・計数所・会計係・商人・寄進）。共通の依頼「売った回数10」。
- 遺物集め：アンデッド・精霊を倒す・遺跡・祭壇・宝物庫で欠片、欠片3で遺物1枚（`SHARD_NEED`）。遺物は同じ種類 2/3/4 枚で 3/6/9、5種そろいで6、年数倍率 1/1.3/1.8。
- どちらも特定のマスに頼りすぎないよう、リーダー・職能の「他人を止める」効果は1ラウンド1回まで（テストで確かめる）。2人が同じ動きを選んでも両方が −3 を下回らないことを測定で確かめる（`SIM_TAGS=trade,trade`）。

### マス・段階カード
- 凱旋：1つの選択肢だけ。倒した種族3以上なら（種族−1）×年数倍率の名声（試合に1回）、足りなければ食料2・素材1。
- 訓練場は熟練だけ。遺跡の探索・祭壇・宝物庫は欠片の入り口。獣舎はどの魔物でも捕まえられる。

### 名声と年数
- 終わりに名声を得る効果（リーダー・職能・道具）は `POINT_SCALE` {5:1, 10:2, 15:3} 倍、「〜ごとに」の数え方としきい値は `TABLE_SCALE` {5:1, 10:1.6, 15:2} で割る。
- 分野表は武器・防具・道具・唱えた秘術・防壁・職能・使い魔など。0 は −1（おすすめのまま）。
- 4種の品物を全部使っていれば名声 `FOUR_KINDS_FAME`=2（年数倍率）。
- 主・古竜に勝つと食料 `BOSS_FOOD`=2。

### 魔物
- 強さの元 s＝8 + 傾き·t（5年15・10年20・15年23）。主は base 6。戦利品 s/3.5、証 s/6.5。
